## Project Overview

We developed a method DropDAE (Dropout Denoising Autoencoder), a novel deep learning framework that improves imputation for high-dimensional data like single-cell RNA sequencing (scRNA-seq).
It uses:

* A denoising autoencoder structure to reconstruct corrupted input data.
* An optional triplet loss based on consensus clustering to improve separation between similar and dissimilar cells.

[View Publication](https://doi.org/10.3390/bioengineering12080829)
